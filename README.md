# behind the coffee 

What makes a coffee shop profitable? A 5 to go case study.

## about the project

Selling more coffee doesn't always mean making more profit.

Using 5 to go as a case study, I want to explore what happens behind the counter from a business perspective: sales, costs, customer demand, and everyday decisions.

The goal is to understand where money is made, where it might be lost, and how data can help a coffee shop run more efficiently.

## questions I want to answer

* What factors have the biggest impact on profitability?
* Which products and hours generate the most profit?
* Can we predict customer demand?
* Where could the business reduce unnecessary costs?
* How would changes in pricing, inventory, or staffing affect profit?

## tools

Python, Pandas, SQL, Scikit-learn, Power BI, and Streamlit.
